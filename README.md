AI Coursework Report: 
This repository contains a comprehensive report on three distinct topics in artificial intelligence, covering practical machine learning applications and a philosophical discussion on large language models.

Task 1: Word Clustering Analysis- 
This section explores an unsupervised learning approach to analyze word relationships.

Methodology: The analysis uses a process of data collection, word selection, and distance measurement to create initial word clusters. Dijkstra's algorithm is then applied to find shortest paths, and a final comparison of the clustering results is presented.

Key Takeaway: The report provides a quantitative and qualitative comparison of different word clustering outcomes, highlighting how methodology changes can impact the final analysis.

Task 2: Classification with Non-linear Decision Boundaries- 
This task focuses on using non-linear models to solve a classification problem.

Methodology: The report examines the effect of boundary curvature on classification and compares the performance of different neural network architectures to find an optimal solution.

Key Takeaway: The analysis demonstrates how different model choices and architectural decisions affect a classifier's ability to handle complex, non-linear data.

Task 3: Personhood and Large Language Models- 
This section presents a philosophical argument about the nature of large language models (LLMs).

Argument: The report explores the question of whether LLMs can possess attributes of personhood or rights. It frames LLMs within a "technological tool" framework, discusses the missing elements required for personhood, and warns of the dangers of anthropomorphism.

Key Takeaway: The report concludes that despite their advanced capabilities, LLMs should be viewed as sophisticated tools rather than sentient entities.
